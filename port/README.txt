SUPER MARIO STRIKERS R36S V0.1

Experimental native PortMaster bring-up build for AArch64 / RK3326 / Mali-G31.

GAME DATA IS NOT INCLUDED.

Copy your own legally dumped USA Super Mario Strikers disc image (G4QE01) to:
  ports/strikers/assets/Super Mario Strikers (USA).iso

V0.1 goals:
  - start on ArkOS / GLIBC 2.30
  - initialize Mali-G31 OpenGL ES
  - reach the game
  - verify SDL controller/audio
  - collect ports/strikers/log.txt

Movies are disabled in this first build on purpose. They will be restored after the core runtime works.

If it exits or shows a black screen, send ports/strikers/log.txt back for the next build.
